To jsou dvě cesty pro spam. V koši už bylo 96 spamových komentářů. Portfolio komentáře nepotřebuje → vypnout úplně. Žádný plugin, žádná údržba, stoprocentní účinnost. A) Vypnout pro nové příspěvky Nastavení → Diskuse: [ ] ODŠKRTNI „Povolit komentáře u nových příspěvků" [ ] ODŠKRTNI „Povolit upozornění z jiných blogů (pingbacky a trackbacky)" Uložit změny B) Zavřít u JIŽ EXISTUJÍCÍCH příspěvků Bod A platí jen pro nově vytvořené příspěvky, staré zůstanou otevřené. Proto: Příspěvky → Všechny příspěvky → zaškrtni všechny → Hromadné akce → Upravit → Použít → u „Komentáře" vyber „Nepovolit" → Aktualizovat Totéž zvlášť pro Stránky. C) Vysypat, co už přišlo Komentáře → Koš → Vysypat koš. Komentáře → Spam → Vyprázdnit spam. Kdyby Jana komentáře někdy chtěla, tak NE takto, ale: plugin Akismet Anti-Spam (pro osobní web zdarma, chce API klíč) + v Nastavení → Diskuse zapnout „Komentář musí být schválen ručně". 7) DOSTAT E-MAIL Z WEBU ========================= U každého článku bylo „by music1919@gmail.com".
